# 📊 Option Chain Analyzer

A powerful, interactive NSE Option Chain analysis tool built with Python and Streamlit.

## 🚀 Features

### 📊 Dashboard
- Complete market overview
- Quick metrics at a glance
- Interactive visualizations

### 📈 OI Analysis
- Open Interest distribution
- OI concentration zones
- OI PCR analysis

### 📉 PCR Analysis
- Put-Call Ratio calculation
- OI PCR, Change PCR, Volume PCR
- Strike-wise PCR visualization

### 📊 Volume Analysis
- Trading volume distribution
- Volume concentration zones
- Volume quality assessment

### 🔄 Change OI Analysis
- OI additions and unwinding
- Call writing / Put writing identification
- Buildup analysis

### 🎯 Support & Resistance
- Key support levels
- Key resistance levels
- Strength assessment

### 💉 Max Pain Analysis
- Option seller's pain point
- Pain distribution visualization
- Market equilibrium analysis

### 💧 Liquidity Analysis
- Bid-ask spread analysis
- Liquidity score
- Market depth assessment
